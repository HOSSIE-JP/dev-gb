# 原本と出典

`game.json`と`images/*.png`が原本です。PNGは固定4階調、CGB色はJSONに保持します。生成Cは次のビルドで置き換わります。

自機・敵・ボス・弾・爆発・背景画像、効果音、ゲーム設定は、このリポジトリの元STAR CARAVANから移行したオリジナル素材です。第三者ゲームの画像・コード・音楽は使用していません。既存商用作品との公式な関係はありません。独自素材の再配布ライセンスはまだ指定されていないため、公開時に所有者が条件を決めてください。

文字は美咲ゴシックからビルド時に生成。作者・条件は`editor/THIRD-PARTY-NOTICES.md`を参照してください。素材を変更した作品では、作品設定の作者・出典・ライセンスも更新してください。
