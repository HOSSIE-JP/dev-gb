## 霊夢ショットの確認

通常 `reimu-shot` は fan / count=2 / spread=30 / speed=8 / interval=12 / delay=10 / lifetime=32 / damage=1。16方向量子化により実角度は上向き±22.5°、速度成分は左右±3、上7.5px/更新。敵の位置を追跡しない固定2Wayです。集中 `reimu-focus` は上向き直進1発・威力2。通常ショットには誘導計算を削減する余地がなく、今回は変更していません。C実装でも `runtime.c` の `steer_sprite_shots()` は敵弾 `CE_ESHOT` だけを対象にし、自弾 `CE_PSHOT` は対象外です。敵との命中判定は別処理として残ります。処理時間の新しい比較計測は行っていないため、ショット全体が軽いという主張ではありません。

3Way案は中央0°を加え左右±22.5°のままにする構成です。中央の敵へ当てやすくなりますが、発射要求は2→3発になり、自弾枠・OAM枠の使用が増えるので性能改善ではありません。現在の扇幅30°を保ちcount=3とするとこの角度になります。
