# v0.10 素材記録

霊夢の陰陽玉、魔理沙スパーク、魔理沙の自機画像を内蔵 image_gen で制作し、原寸PNGをこのフォルダに保存した。`manifest.json` は原画のSHA-256と変換時の切り出し範囲を記録する。

- `marisa-original.png`: 魔女帽子、金髪、白いエプロン、ほうきが分かる上向き飛行姿。ゲーム用には16×24ピクセルへ変換。
- `yinYang-original.png`: 四階調の巨大な陰陽玉。96×96ピクセルで中央に配置。
- `spark-original.png`: 白い芯を持つ極太の上向きレーザー。96×128ピクセルへ変換し、自機の座標に合わせてBGをスクロール。
- `explosionStudy-original.png`: キャラクター別ボムの指定前に生成した共通爆発の検討素材。ゲームでは未使用。

これらは新規生成素材であり、参照ROMから抽出したものではない。キャラクターの原作は東方Project / 上海アリス幻樂団。生成素材の保存は原作キャラクターの権利を移転するものではない。既存のプロジェクトのライセンス・出典情報と合わせて扱う。

リポジトリ直下から `.tools/node/node.exe projects/touhou-kouma/touhou-kouma-design/imagegen-v10/convert.cjs` で原画と取り込み済みPNGの一致を確認できる。`--write` はこの3枚のPNGだけを再生成する。エディターのビルド済みライブラリを使用するため、先に `editor/build.mjs` を実行する。

編集用PNGは `assets-src/images` にある。PNGのグレー値はエディターのインデックス符号化のため画面上の明暗と逆で、ゲームのパレットを通した見え方はROMのスクリーンショットを参照する。
