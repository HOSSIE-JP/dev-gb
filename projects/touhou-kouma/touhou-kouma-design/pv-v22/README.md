# 東方 紅魔巡礼 GB 紹介PV

`touhou-kouma-v22-pv.mp4`: 98秒 / 1920×1080 / 60fps / H.264 + AAC。v0.22の承認済みROMから実際に録画したGBC映像を使用。ゲームの処理落ちは維持し、59.7275Hzの表示映像を時間を変えずに60fpsへ変換しています。終端のタイトルのみ静止したエンドカードです。

構成: 起動ロゴ・二次創作案内 → タイトル → 霊夢/魔理沙のキャラクター選択 → 霊夢の通常ショット・陰陽玉 → 魔理沙の通常ショット・魔理沙スパーク → ボム比較 → 後半レミリア戦 → フランドール戦 → 爆発・弾幕名カットイン・第2/第3パターン。

## 音声について

ゆっくり解説風の掛け合いと顔アイコンを使用しています。ただしAquesTalk等の専用ゆっくり音声環境が確認できなかったため、**音声はWindows標準音声による仮ナレーション**です。霊夢役=Microsoft Haruka Desktop、魔理沙役=Microsoft Ayumi。専用音声の所在・代替音声の希望をユーザーに質問中です。`voice/01.wav`〜`13.wav`を差し替え、`prepare-edit.cjs` と `render.cjs` を実行すると再編集できます。台詞の長さが次の台詞開始を超える場合はタイムラインの調整が必要です。

## 編集・再現用ファイル

完成動画（MP4）、録画素材（MKV）、録画中間ファイル（`frames.rgb`、`audio.s16le`）はローカル保存とし、Git管理から除外しています。新しいクローンには含まれないため、再編集時は保存済みの録画素材を配置するか、`capture.mjs` と `finalize.cjs` で再収録してください。台本・編集スクリプト・字幕・検証記録はGitで管理します。

- `timeline.json`: ショット構成と元動画の使用区間。
- `narration.json`, `narrate.ps1`: 字幕、読み上げ用表記、台詞開始時刻と仮音声生成。
- `subtitles.ass`: 掛け合い字幕、見出し、話者表示。
- `layout.ps1`, `layout.png`: 16:9レイアウト。顔アイコンは既存の二次創作案内画像から使用。
- `capture.mjs`, `captures/*/capture.json`: ROMの録画処理、操作履歴、場面切替の時刻。RAM/ROM改変なし。
- `captures/*/source.mkv`: 編集用のFFV1/PCM録画素材。
- `prepare-edit.cjs`, `render.cjs`, `render-filter.txt`, `render-command.json`: 再編集用スクリプトと実際のFFmpeg引数。
- `manifest.json`: 承認済みROMと動画のSHA-256、素材対応、検証情報。
- `qa/`: フレーム抜粋、全編デコード結果、音量・コーデック検査。

リポジトリのルートから同梱Nodeを使って実行します。`render.cjs` のFFmpegパスはこのPCのインストール先です。初回の承認記録は `approval.json` に保存しています。動画は公開・アップロードしていません。

映像5880フレームと98秒の音声を全編デコードし、字幕の収まり、機体選択、ショット、ボム、後半弾幕、カットイン、最後のタイトルを画像抜粋で確認しました。ピーク音量-0.4dB、平均-22.6dB。人の聴感確認は未記録です。
