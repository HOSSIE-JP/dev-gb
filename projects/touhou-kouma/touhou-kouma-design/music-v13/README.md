## 編集元と再現

compose.cjs に各曲のA/B旋律、調性、コード進行、リズム、展開を記述しています。リポジトリ内のNodeで実行すると score.json、midi/、エンジン側の engine/caravan/assets-src/kouma-score.json を再生成します。MIDIは譜面試聴用で、GBのAPU出力とは音色が異なります。

エディターの通常ビルドが音符を35バイト/小節に変換し、各曲を自動ROMバンク配置します。パルス2の主旋律とウェーブ3の伴奏を使用し、パルス1とノイズ4を効果音に残しています。Cドライバーは小節境界に35バイトをRAMへ読み込み、フレームごとの大量コピーを避けます。曲の行数は16bitで、256行を超える展開も最後まで再生します。旧作品のID1〜15は保持しています。

## 確認

DMG/CGBのGBDK音楽専用ROMで19曲すべての小節、ループ境界、効果音チャンネル非干渉、音声出力を確認します。実行: editor/tests/arranged-music.acceptance.mjs。audit.jsonは譜面上の構成・発音数、qa-v13.jsonはROM実測です。人による聴感評価や実機音声の検証は含みません。

試聴用のWAVは tests が出力したGBCエミュレーターの実APU音声です。音量だけを正規化しています。音楽専用ROMなので弾幕や効果音は含みません。
