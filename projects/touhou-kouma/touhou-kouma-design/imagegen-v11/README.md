# v0.11 機体別イラスト

2026-09-12。霊夢・魔理沙の選択用バストアップ、ゲームオーバー用の困り顔、魔理沙の戦闘前・勝利後の立ち絵を制作した記録です。東方Projectのファンゲーム用素材で、公式作品の画像を抽出したものではありません。

- `*-original.png`: built-in image_gen による原寸生成結果。原画をそのまま保存。
- `*-gb.png`: 160×144、4階調の確認用画像。実際のCGB色はゲームの既存パレットを適用。
- `prompts.json`: 6点それぞれの生成指示全文。
- `manifest.json`: 原画・採用PNGのSHA-256、サイズ、配置、タイル数、保存時のプロジェクトrevision。
- `convert.cjs`: 6枚の元画像から編集用PNGを再現する変換コード。
- `../dialogue-v11.json`: 魔理沙の全7ボス分の戦闘前・戦闘後会話、合計56ページ。

選択画像は上下左右に余白を確保して152×136を(4,4)へ配置。霊夢243／魔理沙245種類のタイルに収めています。左右矢印は画像に含まれ、ゲーム側の性能・番号・文字ヘルプは重ねません。

ゲームオーバーは160×144全体を使い、霊夢181／魔理沙164種類のタイルです。リボンや帽子の崩れ、すす、涙、ため息を描き、ゲーム側で `GAME OVER` と現在スコアを表示します。

会話立ち絵は64×88を(8,4)へ配置し、160×144画像の左上80×96を丸ごと差し替えます。元の霊夢の輪郭も消え、右側のボスと下部の台詞領域を保ちます。霊夢は既存の会話原画を使用します。

変換は中央最近傍サンプリングと4段階量子化です。透過部分は背景色にし、ディザを加えません。編集用PNGはリポジトリの索引色規約により、通常の画像ビューアでは明暗が反転して見えます。見た目は `*-gb.png` またはエディター／ROMで確認してください。

リポジトリ直下で実行:

```powershell
.tools/node/node.exe projects/touhou-kouma/touhou-kouma-design/imagegen-v11/convert.cjs --verify
.tools/node/node.exe projects/touhou-kouma/touhou-kouma-design/imagegen-v11/convert.cjs --previews
```

`--write` は6枚の `assets-src/images/` のPNGを再生成します。通常の検証には `--verify` を使います。旧画像・旧バージョンのデザインデータは保持しています。
