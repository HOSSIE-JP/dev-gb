# v0.7 画像修正

- `rumia-sheet.png`：初回生成原稿。比較用に保持。
- `rumia-sheet-corrected.png`：採用原稿。ユーザーの指示により腕を水平にし、解剖学的な右手（画面左側）をグーへ修正。
- `cirno-sprite.png`：チルノの生成原稿。顔・リボン・羽を大きく整理したデザイン。
- `prompts.json`、`pose-correction.txt`：生成・修正指示。画像生成ツールを使用。
- `*-gb.png`：実際の4階調ピクセルを4倍の整数倍率で表示した確認画像。
- `pixels.json`：変換結果。採用したゲームデータは `../../assets-src/images/` に保存。

リポジトリ直下から `node projects/touhou-kouma/touhou-kouma-design/convert-v07.cjs` で、原稿から確認画像とピクセルデータを再生成できる。これはゲームを自動上書きしない。チルノは面積平均による24×24変換を採用し、最近傍変換の比較画像も保持している。

会話は左に既存の霊夢、右にルーミアの立ち姿。リザルトは左に霊夢、右に膝をついて負けたルーミア、下48pxを得点表示用に空けた。霊夢のピクセルは既存デザインのまま。

前回v0.6の画像原稿・取り込み画像・出典情報とルーミアBGM 32/33の譜面は、隣の `imagegen-v06/` に保存。楽曲は今回変更していない。東方のキャラクターを題材にした生成画像であり、参考ROMからの画像・音源抽出は行っていない。
