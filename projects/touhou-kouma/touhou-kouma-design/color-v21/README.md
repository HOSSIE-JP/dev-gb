# GBCカラー制作データ

既存の構図・キャラクター設定を参照して着色した原画を `*-master.png` に保存しています。元のモノクロ画像は上書きしません。`*-prompt.json` に生成指示と参照情報、`manifest.json` に使用原画のSHA-256と素材の対応を記録します。

対象は68素材・79フレームです。ロゴ、タイトル、会話の立ち絵、カットイン、キャラクター選択、ゲームオーバー、エンディング、ボム、全キャラクター・敵・弾・爆発のスプライト、7ステージのBGを含みます。

`convert.cjs` は原画の縮小・配置・スプライトの透過マスク適用を再現します。画像生成自体は行いません。`--import` を付けるとリビジョンを確認してプロジェクトへ保存します。通常実行はプレビューと変換記録のみ更新します。原画を再生成して基準を変えず、修正時も元データを保存してください。

GBC用PNGは `assets-src/images/*-cgb.png` に独立保存します。ビルド時にRGB555へ変換し、8×8タイルごとにBGは4色、OBJは透明色と3色に最適化します。画像用パレットは1〜7、0はシステム用です。OBJパレットは全スプライトで共通に最適化し、ボス登場時に自機や弾の色が変わらないようにします。循環スクロール用の背景タイル群はパレットを共通化します。

`audit.cjs` は全フレームの独立ソース・透過色・タイル色数・パレット番号を検査し、`audit.json` を出力します。`previews` はGBC制約適用後の画像です。エンディングのGBC画像は160×144。指定された3枚のGB版は、255タイルに収まるまで段階的に縮小します。

東方Projectのキャラクターは上海アリス幻樂団に帰属します。本フォルダのカラー原画は既存の本作制作素材を参照したAI支援による二次創作です。参考ROMから画像データは転用していません。
