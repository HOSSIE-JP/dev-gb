## 再現手順

リポジトリルートで実行します。

```powershell
.tools/node/node.exe editor/build.mjs
.tools/node/node.exe projects/touhou-kouma/assets-src/midi_gb/register-game.cjs
build.cmd touhou-kouma -Configuration Debug
build.cmd touhou-kouma -Configuration Release
```

`register-game.cjs`は編集APIのrevision確認付き保存でプロジェクトを登録し、採用MIDIと元MIDIのハッシュ・出典を`import.json`へ記録します。通常のビルドはMIDIを読み取るだけです。再編曲・量子化・主旋律の再選択はせず、ピッチ、タイ、休符、一定テンポ、ループ長を維持します。MIDIを変更した場合は再登録してからビルドしてください。SHAが一致しないMIDIはビルドを失敗させます。

## 音色と効果音

- CH2：主旋律、CH1：副旋律、CH3：ベース。各声単音。
- MIDIのGM音色は使用せず、マニフェストのパルスデューティーと既存の波形を使用します。波形は曲中に切り替えません。
- パルスのvelocityはGB音量へ量子化し、主旋律の最大音量12、副旋律9を基準にします。自動減衰を使わず、MIDIのノート終了で消音します。CH3はvelocity 76以上を50%、未満を25%へ変換します。
- 通常の連射音は低音量で短いCH4ノイズへ変更し、副旋律を途切れさせません。グレイズ・着弾等が優先です。従来の2声曲では従来のショット音を使います。
- アイテム音等はCH1を短時間使用し、終了後にその時点の副旋律へ戻ります。ボム等の持続音は終了までCH1を保持します。その間もCH2／CH3と音楽の進行は維持します。

3声化の代償は、通常ショット音の音色変更、重要効果音による副旋律の一時欠落、譜面とバッファの増加です。3声の小節データは100バイト（既存2声は35バイト）、3声用のバッファ拡張は指定プロジェクトのみ有効です。CPU負荷とROM容量は実ビルド・実行測定を[ゲーム検証レポート](../../../../docs/touhou-kouma-v44.md)へ記録します。

## 検証の区別

MIDI試聴ページの合成WAVは従来のままです。今回のゲーム検証で保存するWAVは、実ROMをエミュレーターのAPUで再生した音です。どちらも実機録音ではありません。ループと音列の機械的な一致、ゲーム内の割り当てと動作、人による音楽評価を区別します。
