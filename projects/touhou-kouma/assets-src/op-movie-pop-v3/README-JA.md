# SCARLET PILGRIMAGE — ポップなキャラクター紹介OP v3

**10秒×4本、全40秒。** キャラクターの笑顔・視線・小さな仕草を主役にした、明るくかわいいギャルゲーム風OPです。最初の二人の短い飛行から、お茶会、庭園のじゃれ合い、全員の顔アップと集合絵へつなぎます。

[画像と英日プロンプトの確認ページ](review.html)

## 演出

| 時間 | 内容 | 緩急 |
|---|---|---|
| 0–10秒 | 霊夢・魔理沙の登場、背中合わせの笑顔、飛行、縁側 | 中盤3秒だけ強い遠近感で加速し、最後は日常の仕草へ |
| 10–20秒 | 咲夜、パチュリー、美鈴、ルーミア、チルノ | お茶、本、照れた敬礼、おやつ、氷の花で性格を紹介 |
| 20–30秒 | 姉妹の登場、霊夢とレミリアの花びら、魔理沙とフランの帽子いたずら、4人のじゃれ合い | 手前の仕草から瞳へのピント送り、短い回り込み、前ぼけのバラ越しの横移動 |
| 30–40秒 | 9人の顔アップを一人0.75秒→全員集合 | 36.75秒から40秒まで集合絵で締める |

20–30秒は全編が同じ庭園。花びらや指先を短く見せて相手の瞳へピントを移し、表情の反応を中心に見せます。手前のバラ、中央の人物、奥の庭を分け、横移動による視差と短い回り込みで奥行きを出します。6カットの開始時刻は0、1.5、3、4.5、6、7.5秒。最後の2.5秒は姉妹の笑顔へゆっくり寄ります。

**クリップ03の参照は4枚へ変更しました。** Picture 1＝霊夢・魔理沙設定画、Picture 2＝姉妹設定画、Picture 3＝庭園、Picture 4＝新しい絵コンテ03。空の背景はこのクリップには添付しません。

ラストの顔アップ順：**ルーミア→咲夜→チルノ→パチュリー→美鈴→フランドール→レミリア→魔理沙→霊夢**。最後は9人の集合絵で完了します。旧版の一人のタイトル接続画は今回の映像に使用しません。

## 使用方法

1. 各動画は16:9・10秒。音声生成を使う場合もBGMと声はなし、効果音のみ。
2. 確認ページの各クリップの **Picture番号順** に画像を添付します。番号はクリップごとにリセットします。
3. `prompts/clip-0N.en.txt` の全文を使用します。日本語版は確認用です。
4. 絵コンテは構図、三面図は同一性、文章は動作とカメラの参照です。矢印・時刻・注釈は新しい絵コンテに入れていません。動画用プロンプトにも矢印への言及はありません。
5. 最後のクリップでは、Picture 6の9コマが顔アップ9カット、Picture 7が10カット目の集合絵です。各顔は直接カットで切り替え、最後に全員が揃った構図へ切ります。
6. 4本の映像を順にカット接続して40秒。効果音の短い余韻だけを必要に応じてつなぎます。キャラ紹介の編集なので、クリップ間を移動・攻略の連続として補完する必要はありません。

## 素材

- 設定画5枚：旧パックから同じファイルを複製。9人の顔・衣装の基準を維持。
- 新背景3枚：日向の神社、バラ庭園、明るい空。
- 新絵コンテ4枚：前半3枚は6コマずつ、最後は9人の顔アップ。すべて画像内の演出注釈なし。
- 新集合絵1枚：前列はチルノ・霊夢・魔理沙・フラン。後列はルーミア・美鈴・パチュリー・咲夜・レミリア。

新規8枚と既存設定画5枚、計13枚を使用します。旧OP資料は別フォルダー `op-movie-v1/` に残しています。

## 再現・出典・検証

`authoring.cjs` が英日8本とショット表を生成し、`build-review.cjs` が参照整合性を検証して確認ページとハッシュ一覧を作ります。新規画像は内蔵 `image_gen.imagegen` を使用。生成プロンプトと参照ファイルは `provenance/image-generation.json`、画像寸法とSHA-256は `provenance/manifest.json` に記録します。

東方Projectの既存キャラクターとプロジェクトの設定画を使った二次創作資料です。背景と小道具の仕草は今回のOP用の演出として追加しています。

検証結果は [QA-JA.md](provenance/QA-JA.md) と [validation.json](provenance/validation.json)。動画本体の生成、実際のカメラ動作、0.75秒単位の切り替え精度、顔の連続性、効果音の聴取、ゲームへの組み込みは未実施です。
