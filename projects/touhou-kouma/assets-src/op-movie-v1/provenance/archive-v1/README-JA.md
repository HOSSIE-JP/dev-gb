# SCARLET PILGRIMAGE — OP制作パック v1

60秒のアニメOPを **15秒 × 4本** で作るためのH3 Ref2VA用プロンプトと参照画像です。動画本体の生成・編集・ROMへの組み込みはまだ行っていません。

[画像・英日プロンプトの確認ページ](review.html) を開いてください。英語版が投入用、日本語版が確認・調整用です。両方を同時に貼る必要はありません。

## 構成

| 本編時間 | ファイル | 展開 |
|---|---|---|
| 00–15秒 | clip-01 | 霊夢・魔理沙登場 → 森の上空でルーミア戦 → 青い湖霧 |
| 15–30秒 | clip-02 | チルノの氷弾幕 → 紅魔館の門上で美鈴戦 → 入口の暖色光 |
| 30–45秒 | clip-03 | パチュリーの魔法図書館 → 咲夜の時間停止・ナイフ → 紅い夜空 |
| 45–60秒 | clip-04 | レミリア／フランドールとの空中戦 → 4人の対峙 → タイトルへの寄り |

各クリップ6カット、計24カット。ボスは倒さず、決着をゲームに残します。ユーザー記載の「エミリア」はプロジェクト内の人物名に合わせて **レミリア・スカーレット** と解釈しています。

## 動画生成への投入

1. 16:9、15秒、音声生成あり／BGMなしを制作設定とします。出力解像度・fpsは利用する動画生成画面で選べる値に合わせ、4本で統一してください。
2. 確認ページの各クリップの **Picture順** で画像を添付します。番号はクリップごとに1から振り直します。ファイル名と番号の対応は [shot-plan.json](prompts/shot-plan.json) に保存しています。
3. 対応する `prompts/clip-0N.en.txt` の全文を使用します。`subject_definitions` から `non_diegetic_music` まで6節を保ってください。
4. 各プロンプトの時刻は **その15秒内のローカル時刻** です。絵コンテの時刻も同じです。
5. 設定画の複数の向きは同じ人物の設計資料です。絵コンテや背景ボードの枠、ラベル、矢印、分割構図は動画には出しません。
6. 4本を順番に編集して60秒にします。境界は青霧／暖色光／紅雲の色と動きでつなぎ、風の効果音だけ短くクロスフェードします。境界の映像はカット接続なので尺は60秒のままです。
7. クリップ4の最終フレーム参照 `title-bridge.png` は文字のない画です。60秒の直後に既存タイトル画面へ切り替える想定です。生成モデルにタイトル文字を描かせず、既存の `SCARLET PILGRIMAGE` 表示を使用します。

このパックは画面の添付枚数上限やRef2VAの提供状況を保証するものではありません。実際の生成UIで画像の枚数と番号を照合してください。参照番号を変える場合はプロンプトも同時に変更します。

## 画像の役割

- `references/characters-01-heroes.png`：霊夢／魔理沙の三面図、箒・魔法の道具。
- `references/characters-02-rumia-cirno.png`：ルーミア／チルノの三面図。クリップ1は上段だけ、2は下段だけ使用。
- `references/characters-03-meiling-clean.png`：美鈴の三面図。白いズボンを含むプロジェクトの衣装を維持。
- `references/characters-04-patchouli-sakuya.png`：パチュリー／咲夜の三面図と小道具。
- `references/characters-05-scarlet-sisters-corrected.png`：姉妹の三面図。膜の翼と結晶の翼を分離。
- `backgrounds/`：森、湖／門、図書館／時計回廊、紅月の屋根。計4枚・6ロケーション。
- `storyboards/`：15秒ごと6コマ、計4枚。青い矢印＝カメラ、橙色の矢印＝人物の動き。文字で指定した時刻・方向を最終的な指示とします。
- `references/title-bridge.png`：ラストショットの画角とタイトルへの接続。
- `references/title-current.png`：現在のタイトル原画の複製。比較用であり、4本の通常添付リストには含めません。

三面図は新しいアニメ用の補助設定画です。既存原画に見えない背面、魔理沙の下半身、小道具の細部は今回の演出用に補っています。既存ゲームの設定や原画を上書きするものではありません。採用画像は以降の動画生成で固定して使います。

## 音

BGM・台詞・ナレーション・歌・掛け声なし。風、布、札、箒、氷、光弾、ナイフ、時計のクリックなどの効果音のみ。咲夜の時間停止はローカル6.600〜8.200秒の短い静けさで表現します。

## 出典と保存

既存の `touhou-kouma-design/color-v21/` にある人物原画・ステージ原画、`v36-mansion/masters/facade.png`、現在の `assets-src/game.json` の7面構成を確認して作成しました。新規画像は内蔵 `image_gen.imagegen` で生成しています。元原画は保存したままです。

生成に使ったプロンプト全文・参照元・採用履歴は [image-generation.json](provenance/image-generation.json)、ファイルのSHA-256と寸法は [manifest.json](provenance/manifest.json) を参照してください。東方Projectのキャラクターを使用する二次創作資料として扱い、元キャラクターや既存素材に新たな独占ライセンスを付与していません。

## 検証範囲

4本の英日プロンプト、15秒内のカット時刻、全7ボス、参照画像の存在、6節の順序、無BGM・無台詞指定、保存画像の目視を確認しました。86項目の静的照合と標準163テストを通過。結果は [validation.json](provenance/validation.json)、実行範囲は [QA-JA.md](provenance/QA-JA.md) に記録しています。

これは動画用の制作資料です。実際の動き、顔の維持、カットの秒精度、効果音の同期、タイトルへの接続は動画生成後に確認が必要です。ゲームの実行素材や設定は変更していません。
