# SCARLET PILGRIMAGE — OP制作パック v2

40秒のアニメOPを **10秒 × 4本** で作るためのH3 Ref2VA用プロンプトと参照画像です。ユーザーの生成結果で見えた動作矢印を受け、4枚の絵コンテから矢印・ガイド線・注釈文字を除去しました。この改訂版での動画再生成・編集・ROMへの組み込みはまだ行っていません。

[画像・英日プロンプトの確認ページ](review.html) を開いてください。英語版が投入用、日本語版が確認・調整用です。両方を同時に貼る必要はありません。

## 構成

| 本編時間 | ファイル | 展開 |
|---|---|---|
| 00–10秒 | clip-01 | 霊夢・魔理沙登場 → 森の上空でルーミア戦 → 青い湖霧 |
| 10–20秒 | clip-02 | チルノの氷弾幕 → 紅魔館の門上で美鈴戦 → 入口の暖色光 |
| 20–30秒 | clip-03 | パチュリーの魔法図書館 → 咲夜の時間停止・ナイフ → 紅い夜空 |
| 30–40秒 | clip-04 | レミリア／フランドールとの空中戦 → 4人の対峙 → タイトルへの寄り |

各クリップ6カット、計24カット。ボスは倒さず、決着をゲームに残します。ユーザー記載の「エミリア」はプロジェクト内の人物名に合わせて **レミリア・スカーレット** と解釈しています。

## 動画生成への投入

1. 16:9、10秒、音声生成あり／BGMなしを制作設定とします。出力解像度・fpsは利用する動画生成画面で選べる値に合わせ、4本で統一してください。
2. 確認ページの各クリップの **Picture順** で画像を添付します。番号はクリップごとに1から振り直します。ファイル名と番号の対応は [shot-plan.json](prompts/shot-plan.json) に保存しています。
3. 対応する `prompts/clip-0N.en.txt` の全文を使用します。`subject_definitions` から `non_diegetic_music` まで6節を保ってください。
4. 各プロンプトの時刻は **その10秒内のローカル時刻** です。絵コンテは上段左→右、下段左→右の6コマ。時刻とカメラ指示は画像に描かず、ページの時間表とプロンプト本文に置いています。
5. 設定画は人物の同一性、クリーンな絵コンテは構図、文章は動作・カメラ・時間配分に使います。4枚とも `storyboard-0N-clean-v2.png` を添付してください。旧版の画像は再投入せず、参照画像と英語プロンプトをセットで差し替えます。
6. 4本を順番に編集して40秒にします。境界は青霧／暖色光／紅雲の色と動きでつなぎ、風の効果音だけ短くクロスフェードします。境界の映像はカット接続なので尺は40秒のままです。
7. クリップ4の最終フレーム参照 `title-bridge.png` は文字のない画です。40秒の直後に既存タイトル画面へ切り替える想定です。生成モデルにタイトル文字を描かせず、既存の `SCARLET PILGRIMAGE` 表示を使用します。

このパックは画面の添付枚数上限やRef2VAの提供状況を保証するものではありません。実際の生成UIで画像の枚数と番号を照合してください。参照番号を変える場合はプロンプトも同時に変更します。

- `references/characters-02-rumia-cirno.png`：ルーミア／チルノの三面図。クリップ1は上段だけ、2は下段だけ使用。
- `references/characters-03-meiling-clean.png`：美鈴の三面図。白いズボンを含むプロジェクトの衣装を維持。
- `references/characters-04-patchouli-sakuya.png`：パチュリー／咲夜の三面図と小道具。
- `references/characters-05-scarlet-sisters-corrected.png`：姉妹の三面図。膜の翼と結晶の翼を分離。
- `backgrounds/`：森、湖／門、図書館／時計回廊、紅月の屋根。計4枚・6ロケーション。
- `storyboards/storyboard-0N-clean-v2.png`：10秒ごと6コマ、計4枚。元の構図・人物・背景を保ち、動作矢印・ガイド線・注釈文字を除去。動作と時刻は文章で指定します。旧版の絵コンテは履歴として残し、投入リストから外しています。

三面図は新しいアニメ用の補助設定画です。既存原画に見えない背面、魔理沙の下半身、小道具の細部は今回の演出用に補っています。既存ゲームの設定や原画を上書きするものではありません。採用画像は以降の動画生成で固定して使います。

## 音

BGM・台詞・ナレーション・歌・掛け声なし。風、布、札、箒、氷、光弾、ナイフ、時計のクリックなどの効果音のみ。咲夜の時間停止はローカル4.400〜5.650秒の1.250秒間、動きと音を落として表現します。

## 10秒版の緩急

- クリップ1：霊夢と魔理沙の登場は各1秒。ルーミアの一波を読ませてから回避と反撃を連続させます。
- クリップ2：氷が砕ける瞬間から門の槍先へ切り替え、美鈴の掌打と二人の交差を速くつなぎます。
- クリップ3：時間停止の静けさと、時間再開のクリック直後のナイフ回避で速度差を作ります。
- クリップ4：前半の連撃から5.500秒で急減速して対峙。9.500秒でカメラを止め、最後の0.500秒をタイトルへの余韻にします。

動画用の英日プロンプトには矢印への言及を入れていません。方向と運動は被写体の具体的な動作、カメラの位置と移動として記述しています。
