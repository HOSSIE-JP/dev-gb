# 東方 紅魔巡礼 GB v0.35 — 固有背景と陰陽玉の欠け修正

6面の紅魔館を赤系統へ変更し、中央の模様を全7面で固有にしました。2面は連続した氷岸と波のある水面へ変更。霊夢のボムは、モノクロ版の空白判定をカラー版にも適用していた不具合を直し、縮小せず全体を表示します。[変更と検証](../../docs/touhou-kouma-v35.md)、[検証記録](touhou-kouma-design/qa-v35.json)。

v0.34では、BOSS MODEの撃破後に爆発と約1秒の間を追加し、クリア画像を選択機体へ合わせました。道中ボムはスクロール背景と画像を交互表示。全7面の左右を32pxに統一しました。Bの低速中は被弾判定の中心に円を表示します。[変更と検証](../../docs/touhou-kouma-v34.md)、[検証記録](touhou-kouma-design/qa-v34.json)。

v0.33では、ショットの管理スロットにより命中判定を誤って省略する不具合を修正し、敵の被弾判定を拡大しました。ボス戦の余分なVBlank待機を解消し、背景の非表示列とHUD転送、魔理沙レーザーの描画を最適化しました。製品ROMのBGB測定ではGBC終盤ボス26.98→54.37、道中45.17→49.41更新/秒。常時60fpsには達していません。[原因・検証・測定条件](../../docs/touhou-kouma-v33.md)、[検証記録](touhou-kouma-design/qa-v33.json)を参照してください。

タイトルを約12秒放置すると、ランダムステージを自動操作します。道中からボスのカットインを見せ、戦闘を約15秒続けた後にランキングを約8秒表示し、ロゴから繰り返します。デモ中のボタンでタイトルへ戻ります。デモは無敵で、スコアを保存しません。

エディターのプロジェクト設定「展示用オートプレイデモ」で有効・待ち時間を変更できます。[変更と検証](../../docs/touhou-kouma-v23.md)、[ロゴ後の動画再生方式の検討](../../docs/touhou-kouma-video-feasibility.md)を参照してください。ロゴ後の動画再生はv0.24以降に含まれています。

両プレイヤーと全7ボスを2フレームのアニメーションにしました。GB/GBC対応。詳細は `../../docs/touhou-kouma-v22.md` を参照。

全68素材・79フレームをGBC向けにカラー化しました。BG・スプライト・画像演出を含め、タイルごと4色と画像用7パレットを使用します。3枚のエンディングはGBCで160×144、GBで128×112。カラーPNGの取込・書出とプレビューをエディターへ追加しました。詳細は `../../docs/touhou-kouma-v21.md` を参照。

editor.cmd touhou-kouma で開ける7ステージ・68アセットの作品です。霊夢と魔理沙を可愛いバストアップで選択し、それぞれのトホホ顔のゲームオーバーと、全7ボスの専用会話を表示します。選択画面には「キャラクター選択」の見出しと画像の左右矢印があり、性能・番号・文字ヘルプはありません。

チルノ・美鈴・咲夜の横弾を画面下半分へ移しました。道中は各38〜69秒、56〜124体へ拡張。射撃敵の区間と、HP1・反撃なしの8体編隊を倒すラッシュ区間を3回ずつ交互に配置しています。同時敵枠は8体、撃破エフェクトは2個です。

魔理沙の通常弾を細いレーザーへ変更し、発射間隔を8→4更新に短縮しました。集中弾もレーザーで10→6更新。霊夢の札は通常8×8・集中6×8の広い命中判定になりました。機体の被弾判定は変わりません。妖精と使い魔は発射時の自機を狙い、停止・射撃・退出や横切り射撃で本体から弾を分離します。詳細と負荷の比較は `../../docs/touhou-kouma-v20.md` を参照。

v0.32では左120×144pxをゲーム領域、右40×144pxをTIME／HP／MODE／SCORE／LIFE／BOMBの固定HUDにしました。各ボスモードはHP100・60秒（3,600更新）。時間切れは弾消し・上部復帰・次のカットインへ進み、最終モードなら戦闘を終了します。時間切れになったモードの撃破点は入りません。得点単位は旧版の1/10で、旧ランキングも初回起動時に一度だけ換算します。[実装・検証・性能の詳細](../../docs/touhou-kouma-v32.md)。

## 遊ぶ

タイトルでBを10回押すとBOSS MODE／BOSS SELECTに切り替わります。再度10回で解除。選択した面からボスのみを連続で戦い、コンティニューは同じボスからスコア0で再開します。デバッグの得点はランキングに登録しません。

敵弾が自機の当たり判定の外側6px以内をかすめると1発につき1回1点、自機が約0.2秒発光します。無敵・ボム中は加点しません。


DMG/CGB共通ROMは [build/Release/touhou-kouma-v35.gb](build/Release/touhou-kouma-v35.gb)（2MiB）。タイトルの上下でSTART／STAGE SELECT、STAGE SELECT上の左右で01〜07を選択します。A/STARTから機体選択、左右で変更、A/STARTで決定、Bで戻ります。通常のSTARTは1面から開始します。SELECTでランキング。ゲーム中は十字キーで移動、Aで通常射撃、Bで低速・集中射撃、A+Bでボム、STARTで一時停止。

残機0で約1秒待ち、ゲームオーバー画面を表示します。10秒以内にA/STARTを新しく押すと、同じ機体で現在のステージ最初から再開します。スコア0・残機5・ボム2に戻ります。Bまたは時間切れでタイトルへ戻ります。敗北時のスコアがトップ5に入れば、スコアをリセットする前にランキングをSRAMへ保存します。

ボムは残機ごとに2個でステージ間は持越し、HUDのBOMBが残数です。AとBを両方離すまで再発動しません。全弾消去と画面内の敵への30ダメージ、48更新（60更新/秒なら約0.8秒）の点滅演出があります。表示中に新しく現れた敵や画面端から入った敵にも、ボム1発につき1回の30ダメージを与えます。魔理沙は通常3.25・集中1.5ドット/更新、霊夢は2.25・1.0です。

全ボスはHP100×3。弾幕の上限は12/18/22/26/30/36/40発で、左右端・固定位置・48更新だけの追尾を追加しました。HP0で全弾消去→爆発1個→無敵で上部へ復帰→1.20秒の弾幕名カットイン→再開。撃破後の会話を経てスコアを集計し、2秒待ってから新しいA/START入力を受け付けます。

18曲のBGMを約58〜60秒の構成に改作し、専用エンディングBGMを追加しました。撃破ファンファーレは約3秒の新曲です。

## 起動ロゴ

「プロジェクト」→「起動ロゴ（タイトル前）」で最大16枚の画面画像を登録できます。表示秒数はページ別、フェードは共通で片道0.4秒が初期値です。画像ごとにフェードイン／アウトし、任意のボタンで残りをスキップしてタイトルへ進みます。電源投入時だけの表示で、タイトルへ戻るときは再生しません。

AI SLOP GAMESの文字・ハート・星によるPOPロゴ（2.5秒）→ゆっくり霊夢・魔理沙による「このゲームは東方Projectの二次創作STGです。」（5秒）を登録済みです。ロボットは取り除きました。新ロゴの原画・GB用画像・指示全文・変換方法は touhou-kouma-design/imagegen-v16/、二次創作案内と旧ロゴは imagegen-v15/ に保存しています。プロジェクトを開き直すと設定とプレビューに反映されます。

## 編集と保存

「画面・HUD」→「タイトル」のメニュー設定でステージ選択を有効化でき、下4行がメニュー専用になります。中央でメニュー項目とステージの表示をプレビューできます。「自機」の見出し設定で、選択画像に「キャラクター選択」を重ねます。両設定とも保存・再読込に対応し、元画像は維持します。

プロジェクト設定の「コンティニュー」で有効／無効、受付時間（1〜60秒）、ゲームオーバー前の待ち時間（0〜5秒）を編集できます。初期設定は有効・10秒・1秒です。自機の中央プレビューでキャラクター別のゲームオーバー画像とメニューも確認できます。

プロジェクト設定の「エンディング」で自動送り秒数・BGM・集計順・共通画像と追加機体の画像を編集できます。自機の中央プレビューで機体とスライドを選び、ビルドなしで確認できます。原画は touhou-kouma-design/imagegen-v13/、楽譜・全曲MIDI・試聴音声は music-v13/ に保存しています。

プレイヤー設定で機体ごとの選択画像・ゲームオーバー画像を指定し、機体を切り替えてプレビューできます。ステージの「会話とクリア演出」→「追加機体の会話」で、対象機体・戦闘前／撃破後の台詞・背景・左立ち絵を編集できます。中央の戦闘前／撃破後会話プレビューは機体・ページを選べ、保存前の編集が反映されます。ROMのビルドは不要です。

霊夢の会話は既存の設定、魔理沙は専用の前後4ページずつ、計56ページです。魔理沙の立ち絵は戦闘前と勝利後で切り替わり、スコア計算にも勝利姿を引き継ぎます。

追加機体・速度・武器・専用ボム、共通ボムの残数・ダメージ・時間・点滅周期、弾幕の発生位置・レーン・追尾期間と周期、ボスHP・カットイン・集計待ちも引き続き編集できます。ゲームプレビューではZ+Xでボムを試せます。

編集元は assets-src/game.json と assets-src/images/。v0.11で作成した原画6点・採用画像・指示全文・変換方法は touhou-kouma-design/imagegen-v11/、台詞は dialogue-v11.json、当時の実ROMの代表画面は verification-v11/ に保存しています。旧原画とv0.10の変更も保持しています。

v0.12の配置表は touhou-kouma-design/stages-v12.json、検証画面は verification-v12/ です。ステージの敵出現イベントから raid-* の編隊を編集できます。小型使い魔・小型魔導書は既存画像を再利用し、敵定義をHP1・弾幕なしにしています。左右弾の高さは弾幕の発生位置Y・レーン数・間隔で調整できます。
