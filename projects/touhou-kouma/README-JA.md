# 東方 紅魔巡礼 GB v0.7 — 画像統一・GBC性能改善

このチェックアウトのCARAVAN EDITORで `editor.cmd touhou-kouma` を実行して開きます。7ステージ・55アセットの作品です。v0.7では画像・演出とGBCの弾幕処理を改修しました。旧エディターでは追加設定を扱えません。

## 遊ぶ

`build/Release/touhou-kouma.gb` がDMG/CGB共通ROMです。十字キーで移動、Aで通常射撃、Bで低速・集中射撃、STARTで開始・一時停止。会話・リザルトはAまたはSTARTで進みます。リザルト集計後は2秒以上待ち、ボタンを一度離してから押してください。

## 追加した内容

- チルノの前にルーミアの「宵闇の森」を追加。道中・ボスの専用BGM、スプライト、森のタイル、会話絵、リザルト絵、エンディングカットを追加。
- 全7ボスを背景なしのBG弾幕モードに設定。敵弾をOAMから独立させ、最大64発を扱います。
- 攻撃フェーズ開始時にバストアップと弾幕名を0.75秒表示し、効果音を鳴らします。HPしきい値に到達した時点からボスを無敵にし、カットイン中はゲーム進行を停止します。既存の弾は消去します。
- リザルトは集計完了から2秒の入力待ちを設け、連打や押しっぱなしで即座に消えません。

## 編集する

ボスの「ボス戦の表示」で、通常背景／背景なし・スプライト弾／背景なし・BG弾幕を選べます。BG弾の上限は1〜64発です。各攻撃フェーズの「フェーズ開始カットイン」で画像・弾幕名・秒数（0.1〜10秒、小数可）を設定します。中央のフェーズ選択でカットインも確認できます。

ステージの演出設定にある「集計完了後の待ち時間（秒）」でリザルト待ちを変更できます。道中曲は32、ルーミアのボス曲は33です。曲データ本体は `engine/caravan/music.c`、プロジェクトには曲番号を保存します。

## 描画上の制約

BG敵弾は白い2×2ドット、表示位置は2ドット刻みです。移動は小数精度を保持し、当たり判定は表示された2×2の位置に合わせます。素材画像・色・アニメーションはBG敵弾には適用されません。プレイヤー、自弾、ボスはスプライトです。

GBCは64発の4種類の検証配置で約59.73更新/秒。完成ROMのルーミア戦でも測定した153表示フレームで153更新でした。全場面での60fps保証ではなく、DMGは64発の配置により約19.9〜29.9更新/秒です。

ルーミアはHP60へ下げ、6〜8発の弾を48更新ごとに発射するよう緩和しました。
