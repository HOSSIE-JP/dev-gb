# 東方 紅魔巡礼 GB v0.6 — BG弾幕・ルーミア追加試作

このチェックアウトのCARAVAN EDITORで `editor.cmd touhou-kouma` を実行して開きます。v0.5の未保存編集を引き継ぎ、7ステージ・55アセットへ拡張しました。旧エディターでは追加設定を扱えません。

## 遊ぶ

`build/Release/touhou-kouma.gb` がDMG/CGB共通ROMです。十字キーで移動、Aで通常射撃、Bで低速・集中射撃、STARTで開始・一時停止。会話・リザルトはAまたはSTARTで進みます。リザルト集計後は2秒以上待ち、ボタンを一度離してから押してください。

## 追加した内容

- チルノの前にルーミアの「宵闇の森」を追加。道中・ボスの専用BGM、スプライト、森のタイル、会話絵、リザルト絵、エンディングカットを追加。
- 全7ボスを背景なしのBG弾幕モードに設定。敵弾をOAMから独立させ、最大128発を扱います。
- 攻撃フェーズ開始時にバストアップと弾幕名を3秒表示。HPしきい値に到達した時点からボスを無敵にし、カットイン中はゲーム進行を停止します。既存の弾は消去します。
- リザルトは集計完了から2秒の入力待ちを設け、連打や押しっぱなしで即座に消えません。

## 編集する

ボスの「ボス戦の表示」で、通常背景／背景なし・スプライト弾／背景なし・BG弾幕を選べます。BG弾の上限は1〜128発です。各攻撃フェーズの「フェーズ開始カットイン」で画像・弾幕名・秒数を設定します。中央のフェーズ選択でカットインも確認できます。

ステージの演出設定にある「集計完了後の待ち時間（秒）」でリザルト待ちを変更できます。道中曲は32、ルーミアのボス曲は33です。曲データ本体は `engine/caravan/music.c`、プロジェクトには曲番号を保存します。

## 描画上の制約

BG敵弾は白い2×2ドット、表示位置は2ドット刻みです。移動は小数精度を保持し、当たり判定は表示された2×2の位置に合わせます。素材画像・色・アニメーションはBG敵弾には適用されません。プレイヤー、自弾、ボスはスプライトです。

128発で60fpsを維持する実装ではありません。検証用ROMのDMGは約8.5〜14.9更新/秒、CGBは約14.9〜29.9更新/秒でした。重なりの多い弾幕ほど合成費用が増えます。上限と発射間隔で調整してください。

`assets-src/game.json` と `assets-src/images/` が編集元です。追加画像の高解像度原稿は `assets-src/originals/`、出典・変換条件・SHA-256は `assets-src/expansion-provenance.json` にあります。参考ROMのコード・画像・音声を流用していません。
