# SIDE CARAVAN v0.3

GB／GBC用の横スクロールSTGです。宇宙施設→戦艦甲板→炉心を1枚の512×18タイルマップで連続して進み、約60ゲーム秒でボスへ到達します。v0.2の60秒×3面を廃止し、道中の面切替をなくしました。60回のゲーム更新を1秒とするため、実時間は負荷とDMG/GBCで変わります。時間切れはなく、3段階のボスを倒すとクリアします。

```bat
editor.cmd side-caravan
build.cmd side-caravan -Configuration Debug
build.cmd side-caravan -Configuration Release
run.cmd side-caravan -Configuration Release -Emulator BGB
run.cmd side-caravan -Configuration Release -Emulator Emulicious
```

| 操作 | 動作 |
| --- | --- |
| 十字キー | 移動 |
| A長押し | 連射 |
| B | ボム。再使用は離して押し直す |
| START | 開始／ポーズ・再開 |
| タイトルでSELECT | ランキング |

Pは通常→2連→高密度3方向。Lで集中パルスレーザー（4更新間隔・威力3）へ切り替わり、Pを取ると通常系の強化に戻ります。Sは速度を1.5→1.75→2→2.25ピクセル／更新に強化します。Bはボム＋1、1は1UP、＋は500点、Hはバリア＋1（最大3）。初期3機・ボム2個、上限は各9です。

バリアは1被弾で1枚減り、45更新の無敵時間を与えます。ミスはショット1段階低下、速度維持、レーザー解除。60更新後に復帰し、150更新の無敵時間とボム2個で再開します。

背景速度は1ピクセル／更新。「ステージ」→「スクロール px / frame」で変更できます。速度イベントにも対応しています。ボム中も移動・射撃・敵・スクロールを続け、背景パレットを48更新点滅させます。敵への攻撃、敵弾消去、画面内BG破壊は発動時に一度だけ適用します。

破壊BGは285個。薄装甲40点、重装甲100点、補給箱60点で、補給箱にはドロップがあります。密集区間は1画面64個以上。自機は通過可能で、ミスやボム後も破壊状態が残ります。通常破壊の転送は1更新8タイルまでなので、大量に壊すと見た目の消去が遅れることがあります。通常の全撃破・全取得でも上限は29,040点です。

ボスは80×80ピクセルのデザイン（画面の約28%の枠）をBGで描き、スクロールで移動させます。炉心・排気が2コマで動き、BG弾32発を合成します。攻撃が通る弱点と、自機が接触すると被弾する胴体4矩形を別に設定しています。「ボス」→「胴体の接触判定」で編集でき、プレビューの判定表示では弱点が黄色、胴体が赤です。

自機・バリア機・雑魚3種・施設タイル・BGボスはImage Gen原画から制作し、実際の4色PNGへ変換しました。自機4コマ、雑魚各2コマ、ボス2コマを編集できます。原画・プロンプト・SHA-256は[素材記録](assets-src/imagegen-v03/README.md)にあります。

専用の新曲はタイトル約60秒、道中約103秒、ボス約43秒。道中曲には7区間の旋律・和音・音色の展開があります。[譜面](../../engine/caravan/assets-src/side-score.json)は編集可能です。
