# Image Gen / GB production assets

Image Genで作成した6枚の原画を`masters`に保存しています。`prompts.json`は生成時の実際の指示、`manifest.json`は原画SHA-256、パレット、採用タイル、変換レシピの記録です。原画は再生成せず保持します。

ゲーム用データは`../images`の4階調PNGと`../game.json`です。GBでは色番号0がスプライトの透明色になります。GBCの表示色は`#0b1228 / #276382 / #77d5d7 / #fff3c4`、DMGでは既存の4階調設定を使います。

| 素材 | 実データ | コマ数 |
| --- | --- | --- |
| 自機／バリア装着機 | 各24×16 | 各4（8更新／コマ） |
| ドローン／スイーパー／輸送機 | 各16×16 | 各2（8更新／コマ） |
| 施設タイル | 128×32、8×8を64個 | 1 |
| BGボス | 80×80のデザインを160×144へ配置 | 2（16更新／コマ） |

変換はパレットへの量子化、等間隔セルの切出し、実ピクセルサイズへの標本化です。自機の余白を切り詰め、剛体部分を1コマ目に位置合わせし、生成された噴射部分をアニメーションに使います。ボスも装甲を固定し、生成された炉心・排気部分を差し替えます。BGアニメは最大32タイル差分の転送制限に収めています。施設原画128タイルのうち64個を採用し、HUD・スプライト・弾合成用のVRAMを確保します。

制作レシピは`editor/scripts/revise-side-caravan-v03.cjs`です。既知のv0.2ソースに対する一度だけの変換で、変更済みプロジェクトへの上書きを拒否します。通常の編集・保存・ビルドでは原画生成やこの変換を実行しません。

原画と採用素材はこの作品向けのオリジナルです。商用ゲームのキャラクターや画像を使用していません。オリジナル部分はリポジトリのMIT Licenseに従います。
