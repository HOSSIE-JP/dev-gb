# 素材と制作データ

自機、敵、TRIPLE CORE、5種類のアイテム、弾、爆発、施設タイル、タイトル・結果・ボム画面は、この作品向けにピクセル単位で作成したオリジナル素材です。編集可能な4色PNGを`images`へ保存しています。制作レシピはリポジトリ内の`editor/scripts/create-side-caravan.cjs`です。商用ゲームの画像・音楽・マップデータは使用していません。

敵編隊、ステージ構成、281個の破壊物と強化の設定は`game.json`で編集できます。PNGの再生成や初期データの再作成は、通常の保存・ビルドでは行われません。

BGMは共通エンジンの既存オリジナル楽曲を選曲しています。タイトル1、道中2、ボス5、クリア6、ゲームオーバー7、撃破ファンファーレ8を使用します。新規作曲ではありません。音楽の表示は`engine/caravan/MUSIC-LICENSE.txt`を参照してください。
