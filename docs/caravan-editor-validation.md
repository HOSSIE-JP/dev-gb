## GUIからの編集確認

Computer Useで実際のElectronウィンドウを操作し、STAR CARAVANから`caravan-lab`を複製しました。次の変更をGUIから行い、保存してアプリを閉じ、再起動して復元を確認しました。

- 自機画像に青い1ドットを追加。
- 最初の敵のHPを2へ変更。
- 自機弾の速度を5へ変更。
- ボスHPを40へ変更。
- マップ左上に壁を配置。
- タイトル文字を「スター キャラバン」へ変更。

GUIビルドが32KiBで成功し、内蔵ROMプレイヤーのDMG／CGB双方でかなタイトルとゲーム背景を表示しました。キーボード入力、仮想Aボタンからの開始、一時停止を確認しています。全編集ツールのドラッグ操作を網羅したGUI自動回帰テストではありません。新規作品・複製・保存のデータ経路は別途自動テストで検証しています。

## 未達・未検証

1. **DMGの処理速度が不足しています。** 初期作品のA連射を600エミュレーションフレーム実行した最終計測例で、論理更新は358 ticksでした。更新順序の一致は確認しましたが、ゲーム内120秒＝実時間120秒の保証は未達です。CGB倍速専用にはしていません。性能最適化後、敵・弾・32×32ボスが多い場面も再測定してください。
2. スプライトは最大32×32の矩形を8×8へ分割する方式です。非矩形メタスプライトのタイルを自由配置する専用UIは未実装です。画像の矩形コピー／貼付と原点・判定・発射位置の編集は使用できます。
3. Emuliciousはプロセス／ウィンドウの起動まで確認しましたが、操作許可待ちがタイムアウトし、DMG/CGBの目視・入力・聴感確認は未完了です。BGBのDMG個別設定での確認も残ります。
4. 音はWASMの非ゼロ音声サンプルを自動確認しています。BGB／Emulicious／実機の聴感確認は未完了です。
5. 実機DMG/CGBは接続されておらず未検証です。OAM走査線制限による欠け方、LCD割込みの相性、実時間速度、音を実機で確認してください。
6. 乱数は使用していません。`seed`は予約設定です。保存途中の通常エラーとジャーナル復旧は検査しましたが、任意の瞬間の停電を網羅するものではありません。

このため、計画の全受入条件を完了した完成版とは扱いません。

## 再検査

```bat
doctor.cmd
test.cmd
build.cmd star-caravan -Configuration Release
.tools\node\node.exe --test editor\tests\integration.test.mjs
editor.cmd caravan-lab
run.cmd star-caravan -Emulator BGB
run.cmd star-caravan -Emulator Emulicious
```

ヘッドレス検査画像・診断ROMは`.cache/editor-qa`、一時検証作品はテスト終了時に削除します。クリーン操作で削除するのは再生成可能なbuild／generatedのみです。旧`projects/star-caravan/src/main.c`は作品データ＋共通ランタイムへ置換し、元コードはGit履歴から復元できます。元画像や設定は`assets-src`へ移行済みです。
