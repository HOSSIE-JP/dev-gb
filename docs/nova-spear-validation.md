# NOVA SPEAR の確認項目

NOVA SPEARは`assets-src/game.json`とPNGを共通Caravanランタイムでビルドします。エディターの新規作品でテンプレートに選ぶと、素材・ステージ・ゲーム設定を独立した作品へ引き継ぎます。

## 作品の受入条件

| 項目 | 期待する動作 |
| --- | --- |
| 基本操作 | Aは拡散、Bは集中・低速移動、STARTは開始とポーズ |
| HUD | 上端1行に得点と残機を表示。制限時間とTIME表示は無効 |
| 被弾 | 自機と自弾が消え、90論理更新後に復帰。待機中も敵と背景が進む |
| ステージ | 3面を順に進み、各ボスの全攻撃フェーズに到達できる |
| 撃破 | 複数箇所の爆発、ボス本体の消失、Victory Flareの完奏後に切り替わる |
| フェード | 次面へフェードアウト・イン。最終面はクリア画面へ進む |
| 保存 | ゲーム終了時の上位5件を保存し、電源再投入相当の再起動で復元する |
| テンプレート | 新規作成・複製後に再読込でき、元作品の画像・設定を変更しない |

`editor/tests/nova-spear.test.mjs`と`nova-spear.acceptance.mjs`が作品データと短縮実ROMの回帰検査を担当します。保存の破損耐性は`save.acceptance.mjs`で検査します。実行方法と自動テストの限界は[検証ガイド](caravan-editor-validation.md)を参照してください。

## プレイテスト

公開するROMそのもので、DMG/CGBの全3ステージを通常操作で確認してください。短縮テストの成功や別バージョンの全編クリアは、そのROMの全編確認を代替しません。

処理落ち、1走査線のスプライト欠け、実機の液晶表示・音・保存は個別に評価します。性能比較の手順は[性能測定](nova-spear-performance.md)に記載しています。
