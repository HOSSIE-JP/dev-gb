本番Release ROMのゲーム定義・HP・残機・ステージ時刻を一切変更せず、DMG/CGBそれぞれで全3ステージ・全11ボスフェーズを経てクリアしました。自動操縦は読み取り専用で状態を観測し、通常の十字キーとA/B入力だけを送ります。RAMへの書き込みや無敵化は行っていません。

| モード | 最終得点 | 残機 | ゲーム更新tick |

| DMG | 46,620 | 4 | 11,907 |

別途、無改造のゲーム定義を使ったシミュレーションでも入力の記録・再生を行い、46,520点・残機5のクリアと最終状態の一致を確認しました。ハードウェアモードで描画や入力のサンプリング間隔が異なるため、実ROMの自動操縦経路と得点は完全一致を目的としていません。

## 再現手順

Windowsの固定環境ではリポジトリのルートから実行します。

```bat
bootstrap.cmd
doctor.cmd
build.cmd nova-spear -Configuration Debug
build.cmd nova-spear -Configuration Release
test.cmd
editor.cmd nova-spear
```

`editor`内の`npm run check`で利用可能な全回帰テストを実行できます。GBDKのないホストではROM検証がスキップされるため、`npm run test:rom`で前提条件不足をエラーにして実行してください。CIも`test.cmd`とReleaseビルドを実行し、`nova-spear-game-boy`にプレイ用ROMを保存します。

## 確認範囲

今回のローカルROM実行はBoytaceanのDMG/CGBエミュレーションです。BGB／EmuliciousのGUI、実機カートリッジでの動作と聴感確認はこの実行環境では未実施です。ゲーム内の秒数は60Hzの論理更新に基づき、負荷時の処理落ちは残ります。スコアは起動中のRAM内のみで電源断後は保持しません。

ソースと検証作業用コピーのSHA-256を照合してから検証しました。共有作業ディレクトリでのビルドロック干渉を避けるため、ROM検証は独立した一時コピーで実施しています。生成ROM、スクリーンショット、録画はGitの追跡対象に含めません。

## エディター操作

production版のReact画面をブラウザーで操作し、実際のプロジェクト保存・GBDKコンパイラー・WASM ROM再生へ接続して確認しました。NOVA SPEARの作業用複製で、タイトル編集、Undo/Redo、保存、全素材検索、コマンドパレット、タイル選択・描画、F5相当のビルドしてプレイ、ポーズ／ステップ、再プレイ、別作品への切替と再ビルドが成功しています。ページエラー0件。OS固有のElectronウィンドウ／ファイルダイアログの検証とは分けて記録しています。

160×144背景の変換は、png2assetの中間マップが256タイルを超えないよう完全なタイル行で分割しています。結合後は元画像の2bppデータとの完全一致を検査します。最終変換処理でNOVA SPEAR ReleaseとSTAR CARAVAN Debugを再ビルドし、変換ツールの警告0件、修正前後のROMバイト列一致を確認しました。
