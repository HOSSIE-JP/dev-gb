## 再現手順

Windowsの固定環境ではリポジトリのルートから実行します。

```bat
bootstrap.cmd
doctor.cmd
build.cmd nova-spear -Configuration Debug
build.cmd nova-spear -Configuration Release
test.cmd
editor.cmd nova-spear
```

`editor`内の`npm run check`で利用可能な全回帰テストを実行できます。GBDKのないホストではROM検証がスキップされるため、`npm run test:rom`で前提条件不足をエラーにして実行してください。CIも`test.cmd`とReleaseビルドを実行し、`nova-spear-game-boy`にプレイ用ROMを保存します。

## 確認範囲

今回のローカルROM実行はBoytaceanのDMG/CGBエミュレーションです。BGB／EmuliciousのGUI、実機カートリッジでの動作と聴感確認はこの実行環境では未実施です。ゲーム内の秒数は60Hzの論理更新に基づき、負荷時の処理落ちは残ります。スコアは起動中のRAM内のみで電源断後は保持しません。

ソースと検証作業用コピーのSHA-256を照合してから検証しました。共有作業ディレクトリでのビルドロック干渉を避けるため、ROM検証は独立した一時コピーで実施しています。生成ROM、スクリーンショット、録画はGitの追跡対象に含めません。
