# v0.16 ロゴ修正とコンティニュー

[DMG/CGB共通ROM](../projects/touhou-kouma/build/Release/touhou-kouma-v16.gb) — 1,048,576 bytes、Debug/Release同一。

SHA-256: `408ccecf2ea73cd6d098642fdf4db536cfbf9034b7d43dc8df1cd51b5239f16c`

## 遊び方と変更内容

- AI SLOP GAMESのロボットを取り除き、太いPOP文字・ハート・星のロゴに差し替えました。2枚目の二次創作案内と起動フェードは維持しています。
- 最後の残機を失うと、ステージ進行を止めて爆発を表示し、約1秒待ってゲームオーバー画面へ移ります。
- ゲームオーバー画面に取得スコアと10秒のカウントダウンを表示します。時間内に新しく **A／START** を押すと、選択中のキャラクターで **現在のステージの最初** から再開します。スコア0、残機5、ボム2、初期位置・出現イベント・ボス状態に戻ります。
- **B** または時間切れでタイトルへ戻ります。ゲーム中からの押しっぱなしでは再開せず、期限到達フレームの入力も受け付けません。STARTでの再開直後に一時停止へ入ることも防いでいます。
- 敗北時のスコアがトップ5に入れば、その時点でランキングへ挿入してSRAMへ保存します。コンティニューによるスコア0へのリセットより先に保存し、メニュー表示中や再開時には重複登録しません。既存の2スロット・CRC付き保存形式を維持しています。

## エディター

「プロジェクト」→「コンティニュー」で有効／無効、受付時間（1〜60秒）、ゲームオーバー前の待ち時間（0〜5秒）を編集・保存できます。待ち時間はコンティニューの有効／無効と独立しています。設定のない旧プロジェクトは従来どおり待ち時間0・コンティニューなしです。

自機の中央プレビューでは、霊夢／魔理沙それぞれの画像にメニューを重ねて確認できます。画像下部40pxをメニュー領域として生成時に空け、元のゲームオーバー画像は書き換えません。ビルド不要のゲームプレビューにも待ち時間・カウントダウン・ステージ再開を反映しました。ゲームプレビューは終了時にゲームオーバー画面で止まるステージ確認用で、タイトル遷移とSRAM保存の確認にはROMプレイヤーを使います。
