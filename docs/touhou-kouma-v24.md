# 東方紅魔郷 GB v0.24 — ロゴ後の動画再生

指定動画の非性的な冒頭の顔アップ3.6秒を、音声付きでROMへ組み込んだ。元ファイルは変更していない。後半の映像は取り込まず、ファイル内の生成プロンプト等のメタデータもコピーしていない。

起動および展示ループは「ロゴ → 動画 → タイトル → ランダムステージの自動プレイ → ランキング → ロゴ」。ロゴまたは動画中のボタンでタイトルへ戻り、そのボタンを押し続けてもゲーム開始へ流れない。エディターのプロジェクト設定「起動動画（ロゴの後）」で有効／無効を切り替える。

## 映像・音声

- GBC: 160×96、各8×8タイル4色、画像用7パレット。
- GB: 112×64、4階調、中央表示。
- 36フレーム、6 VBlankごとの更新（約9.95fps、3.616秒）。
- CH3による8192Hz／4bitモノラルPCM。原音の音質を保持する方式ではない。
- 再生中だけエンティティ配列の領域を借用する。静的RAM＋OAMは従来と同じ7,164／8,192バイトで、スタック用1KBを確保。

MP4を実行時に解凍する方式ではなく、事前変換したタイル画像・パレット・PCMを再生する。現形式の上限は36フレーム。変換手順と内部仕様は [startup-movie.md](startup-movie.md)、元素材の出典・抽出範囲・変換設定は作品の `touhou-kouma-design/movie-v24` に保存した。
