# 東方 紅魔巡礼 GB v0.20 — 通常ショットと道中射撃

## 変更

| 対象 | v0.19 | v0.20 |
| --- | --- | --- |
| 魔理沙・通常 | 星弾、8更新間隔 | 8×16のレーザー弾、4更新間隔 |
| 魔理沙・集中 | 光弾、10更新間隔 | レーザー弾、6更新間隔 |
| 霊夢・通常札 | 命中範囲4×4 | 命中範囲8×8 |
| 霊夢・集中札 | 命中範囲4×4 | 命中範囲6×8 |
| 妖精 | 下向き固定、弾速1.25 | 発射時の自機狙い、弾速2.5 |
| 使い魔 | 下向き固定、弾速1.5 | 発射時の自機狙い、弾速2.75 |
| 魔導書 | 移動中に低速二方向弾 | 停止後に二方向弾、弾速2 |

魔理沙のレーザーは細い独立弾の連射で、貫通する常設ビームではない。弾速は既存の対応上限8px/更新、命中範囲は2×16。通常威力1、集中威力2を維持。霊夢の二方向拡散と通常12更新間隔を維持し、両キャラクターの**被弾判定3×3は変更していない**。

妖精の直進・左右派生は、32更新で上部へ進入→停止→44更新で一度だけ狙い撃ち→64更新から退出する。蛇行妖精は移動を継続しながら同じ狙い弾を撃つ。横断する使い魔は24更新で自機へ発射し、本体の横移動から弾が分離する。停止型魔導書は48更新で止まり、64更新で撃つ。移動型魔導書は下降速度を1.125→0.75に下げた。

発射後に曲がる追尾弾ではなく、発射した瞬間の自機位置を狙う。以前の「上向きの弾を作らない」条件を維持するため、`aimed-down`（狙い撃ち・下半面のみ）をエンジンとエディターに追加した。自機が敵の上へ回った場合は左右の水平弾に制限する。従来の全方向の狙い撃ちは変更しない。コンパイラー、プレビュー、実ROMで同じ処理を使う。

既存の武装なし・HP1の突撃編隊、ステージ配置、ボス弾幕、HP100×3、ボム、メニューは維持。エディターの弾幕方式から新方式を選び、保存・再ビルドできる。
