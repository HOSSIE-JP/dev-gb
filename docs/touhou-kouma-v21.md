# Touhou Kouma v0.21 — GBCカラー対応

## 変更

全68素材・79フレームに独立したGBC用カラーPNGを追加しました。ロゴ、タイトル、キャラクター選択、会話、カットイン、ゲームオーバー、エンディング、ボム、全スプライトと7ステージのBGを対象としています。カラー原画、生成指示、変換スクリプト、SHA-256の対応表は `projects/touhou-kouma/touhou-kouma-design/color-v21` に保存しています。

GBCの背景は8×8タイルごとに4色、スプライトは透明色と3色を選択します。画像にはパレット1〜7、システムには0を使用します。スプライト用の7パレットは自機・敵・ボス・弾・エフェクトをまとめて最適化し、各タイルにパレット属性を付けます。スクロール背景の属性更新、循環スクロール、画像切替時のパレット読込とフェードも対応しました。

画面画像はGBCの2つのVRAMバンクを利用します。カラーの画面データ表はROMの別バンクに置き、現在の画面情報だけをRAMに保持します。ボムの画像転送は自機や敵のOBJタイルを保護します。セーブ処理は固定バンクから自動配置へ移しました。SRAMのレコード形式は変更していません。

背景とOBJのパレットはハードウェア上で独立しており、それぞれ8組あります。背景属性の下位3ビットでパレット、ビット3でVRAMバンクを選びます。[Pan Docs: palettes](https://raw.githubusercontent.com/gbdev/pandocs/master/src/Palettes.md)、[tile maps](https://raw.githubusercontent.com/gbdev/pandocs/master/src/Tile_Maps.md)。

ルーミア・霊夢・魔理沙のエンディングはGBCで160×144の全画面表示に統一しました。GB版の3枚はタイル制限に収めて縮小表示します。それ以外のGB画像の画素データは保持しています。

エディターにはGBC用カラーPNGの取込・書出を追加しました。GB用画像とカラー用画像を独立して保存し、カラー表示ではタイル制約適用後のプレビューを表示します。素材、スプライト、ステージ、会話、機体別画面のプレビューを対応しました。

## 性能と残る確認

同じ1面・120〜1000更新・A射撃ルートを比較した論理更新数/秒です。PPUの表示フレーム数とは区別しています。

| 機種・機体 | v0.20 | v0.21 |
|---|---:|---:|
| DMG 霊夢 | 45.35 | 41.42 |
| DMG 魔理沙 | 33.35 | 33.04 |
| GBC 霊夢 | 59.39 | 58.73 |
| GBC 魔理沙 | 57.13 | 54.64 |

カラー属性の算出をSM83アセンブリにし、GBではカラー表参照を省きましたが、描画処理の増加による負荷は残ります。常時60fpsは未達です。Emuliciousは今回もDAP evaluateのNullPointerExceptionで検証未完。実機の発色、手動コントローラー操作、音の聴感、通常難易度の全編評価は未確認です。検証記録は `touhou-kouma-design/qa-v21.json` と `qa-v21/` に保存しています。
