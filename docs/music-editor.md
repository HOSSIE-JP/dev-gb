# MIDI取り込みと音楽編集

Caravan Editorの左側「音楽」から、MIDIをGB向け3声の楽譜へ変換し、取り込んだ曲を修正できます。同一のMIDIバイト列・変換設定・変換器バージョンから同じ楽譜を作ります。ビルド時は保存した楽譜から曲データを生成します。元のMIDIを変更しません。

これは音符を機械的に変換する機能です。どのパートを主旋律にするか、どの区間を残すか、和音のどの音を採用するかは取り込み画面で指定します。サビの選定や音楽的な編曲の良し悪しを自動判定する機能ではありません。

## 開く

ソース版を更新した場合はエディターをビルドして再起動します。

```bat
.tools\node\npm.cmd --prefix editor run build
editor.cmd touhou-kouma
```

「音楽」を選ぶと、東方プロジェクトでは登録済みの14曲がそのまま表示されます。表示しただけでは作品を変更しません。選択して編集すると、その曲の編集用楽譜を作品に保持します。既存のステージ1〜7の道中・ボスの割り当ても引き継ぎます。

## MIDIを取り込む

1. 「MIDIを取り込む」から `.mid` / `.midi` を選びます。
2. 曲の保存先ID（16〜37）、曲名、開始位置（四分音符単位）、小節数、テンポを指定します。
3. 主旋律（CH2）、副旋律（CH1）、ベース（CH3）へ、元MIDIのトラック／チャンネルを割り当てます。空の声も選択できます。必要なら声ごとにオクターブを移動します。
4. 同時発音の扱いを指定します。既定はエラーです。「高音」「低音」「後発音」を選ぶ場合、重複を処理したステップ数を変換結果で確認します。
5. 変換結果を確認し、「この設定で取り込む」を押します。既存のIDを置き換える場合は対象曲を確認します。
6. 試聴・修正して、通常の「保存」またはCtrl+Sで作品を保存します。

IDは曲の参照先です。同じIDに上書きすると、そのIDを使うすべての場面が新しい曲になります。16〜37の22枠には内蔵曲もあるため、割り当てを確認してください。取り込み画面の結果確認だけではファイルを保存しません。取り込みを確定すると元MIDIの保管コピーを作り、作品への反映は通常の保存で確定します。取り消した際も保管コピーは残ります。

### 変換の制約

| 項目 | 対応 |
|---|---|
| MIDI | SMF 0 / 1、PPQ 1〜9600、4 MiB以下、最大128トラック、20万イベント以下 |
| 音域 | C2〜B6。範囲外はエラー。勝手に音程を丸めません |
| 編成 | CH2主旋律＋CH1副旋律＋CH3ベース、各声は単音 |
| 時間 | 4/4相当の1小節16ステップ、1〜64小節。音符の開始・終了を最寄りの16分音符へ量子化 |
| テンポ | 指定した一定テンポを、整数／半VBlankフレーム刻みで再生できる最寄り値へ変換 |
| 強弱 | ベロシティをGB側の離散音量へ変換。ベースの音量段階は少なめ |
| 対象外 | SMPTE時間、SMF 2。ペダル・ピッチベンド・コントローラー・SysEx・GM音色の再現 |

未使用レーン、区間外、区間端で切った音、量子化、同時発音の省略、無視するメッセージは変換レポートに記録します。元の細かなテンポ変化は一定テンポへ置き換わります。ドラムや多数の楽器を含む原曲は、採用する3パートや区間を人が選ぶ必要があります。元曲の拍子が異なっても自動で拍子に合わせた編曲は行いません。

## 楽譜を修正する

- 曲名・テンポ・ループの有無を変更できます。画面には採用テンポと尺を表示します。
- 小節を選び、3列の音符表でセルを選択します。音程、長さ（ステップ数）、音量を編集します。「休符」「タイ」を明示します。
- 長さは小節境界をまたげます。タイだけが取り残されないよう、音符・小節の変更後に整合性を検査します。
- 小節の追加、コピー、貼り付け、削除と、選択した声・小節内の音符のオクターブ移動ができます。
- 小節ごとにパルスのデューティとベース波形、区間名を変更できます。
- Ctrl+Z / Ctrl+Y、未保存の確認、復旧、作品の複製は通常の作品編集と共通です。
- 画面下部でタイトル、共通ボス、クリア、ゲームオーバー、エンディング、各ステージの道中・ボス曲を割り当てます。撃破ファンファーレにはループしない曲を指定します。

「空の曲を作る」から4小節の曲を作り、MIDIなしで音符を入力することもできます。編集対象は取り込んだ曲と作成した曲です。内蔵の全曲を自動で編集用楽譜へ展開する機能ではありません。

### ピアノロール

4小節ずつ、縦軸が音程・横軸が時間のピアノロールを表示します。主旋律は青、副旋律は橙、ベースは緑です。「編集声部」で選んだ声を操作し、他の声を薄く重ねて確認できます。小節ボタンや前後の4小節ボタンで移動し、横幅の切り替えとスクロールで拡大・移動できます。

- 空白をクリックして16分音符を追加します。押したまま横に伸ばすと長い音になります。
- 音符の中央をドラッグすると音程と開始位置を変更します。右端をドラッグすると長さを変更します。
- 右クリック、Delete / Backspace、または「選択音を削除」で消します。
- 音符を選んで矢印キーで1ステップ／半音移動、Shift＋左右で長さ、Shift＋上下でオクターブを変更できます。
- 小節をまたぐタイは1本の音符として表示します。移動時は音符内の音量変化を保ちます。
- 各声は単音のため、同じ声で重なる範囲は新しい音で置き換えます。操作1回ごとにCtrl+Zで戻せます。他の声は変更しません。

ピアノロールと下の音符表は同じ楽譜を編集します。選択した音符は音符表側の音程・長さ・音量欄でも調整できます。試聴中は再生位置を縦線で表示します。

## 試聴とROM確認

「全曲試聴」または「この小節を試聴」を押します。3声を個別にON/OFFでき、主旋律や副旋律だけを確認できます。ループ試聴にも対応します。編集中、作品切り替え、ウィンドウからフォーカスを外した際は再生を停止します。

試聴はWebAudioによる近似GB音です。GBの周波数量子化、パルスのデューティ、エンジンの波形・音量・フレーム間隔を反映しますが、APUの完全なエミュレーションではありません。保存してF5でビルドしたROMを再生し、ゲーム中の音量や効果音との重なりを別途確認してください。

3声曲の通常ショット効果音はノイズCH4を使います。重要な効果音はCH1を一時的に借りるため、その間は副旋律が途切れ、効果音終了後に復帰します。従来の2声曲も再生できます。DMG対応作品ではRAMを抑えるために3声の音量データをステップごとに読み込みます。

## 保存形式と再現性

- 元MIDI：`assets-src/music/sources/<SHA-256>.mid`。読み込んだバイト列を保持します。
- 編集用楽譜：`assets-src/game.json` の `musicTracks`。音符、タイ、休符、音量、テンポ、ループ、小節の音色、出典、SHA-256、変換オプション、変換器名 `smf-grid-v1` を保存します。
- 既存の `musicScore` マニフェストも読み込みます。同じ曲IDに編集用楽譜がある場合は、編集用楽譜を優先します。
- 保存・複製時は元MIDIのSHA-256を確認し、欠落や内容変更を検出します。作品フォルダー全体をバックアップしてください。
- `generated` のCデータは毎回楽譜から生成します。直接編集しません。編集後の楽譜がビルドの入力となり、毎回元MIDIから未編集状態へ戻すことはありません。

変換関数は `editor/src/node/midi-import.ts` の `readMidi` / `convertMidi`、保存への橋渡しは `music-project.ts`、楽譜の共通定義は `shared/music-score.ts` にあります。

## 開発用検証

```bat
.tools\node\npm.cmd --prefix editor run typecheck
.tools\node\npm.cmd --prefix editor run test:music-ui
.tools\node\node.exe --test editor/tests/music-editor.test.mjs editor/tests/midi-soundtrack.test.mjs
.tools\node\node.exe editor/tests/music-editor-rom.acceptance.mjs .cache/music-editor/edited-rom
```

最後のROM検査は、直前の実Electron音楽UIテストで保存した作品を使用し、GBDKを必要とします。GUIテストはファイル選択・上書き確認のOS境界だけを制御し、実際のElectron画面・IPC・ファイル保存・WebAudioを操作します。標準コマンドと検証結果は[検証記録](music-editor-validation.md)を参照してください。
