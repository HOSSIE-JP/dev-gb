# 東方紅魔郷風STG v0.42 — グレイズ・低速操作

## 変更内容

グレイズ1回の加点を10点に変更した。ランキングの形式・セーブ識別子は維持し、既存スコアの再換算はしない。

| 操作 | 動作 |
|---|---|
| A | 通常射撃 |
| Bのみ | 低速移動。ショット・レーザーは出ない |
| Aを保持してB、またはBを保持してA | 低速射撃。ボムを消費しない |
| A/Bを両方離した後、同じゲーム更新でA+Bを押す | ボムを1回発動 |

ボムは押し続けても再発動せず、片方だけ離して押し直しても再発動しない。両方を離して再度同時押しすると次のボムを使える。霊夢・魔理沙とも同じ操作で、魔理沙はAを離すとレーザーが停止する。

`player.focusRequiresA`を追加し、東方で有効にした。未設定の既存プロジェクトは従来操作を維持する。エディター設定・操作案内・シミュレーションも対応した。
