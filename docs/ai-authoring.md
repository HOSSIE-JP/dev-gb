# AIと作るGame Boy STG

`build-gbdk-stg`は、このリポジトリのエディターと共通エンジンを使う制作スキルです。タイトルやステージ数をプロンプトで指定し、編集可能な作品データ・ROM・プレイテストを作成します。

## 導入

スキル本体は[`.codex/skills/build-gbdk-stg`](../.codex/skills/build-gbdk-stg)です。対応するAIクライアントで、このディレクトリをスキルとして読み込んでください。ZIPを扱うクライアントでは、`SKILL.md`と`agents`・`assets`・`references`・`scripts`を含むフォルダーをまとめます。

スキルにSDKやエディター本体は含まれません。実行環境でこのリポジトリを取得し、ロックされた依存ツールを準備する必要があります。AIクライアント側にもファイル編集・コマンド実行の機能が必要です。[利用・再配布条件](licensing.md)も適用されます。

## 依頼例

```text
build-gbdk-stgを使ってGB/GBC向けの縦STGを作ってください。
タイトルは ORBIT LANCER、全3ステージ、残機5、時間制限なし。
宇宙要塞が舞台で、Aは拡散、Bは集中ショット。
各面にボスと撃破演出を設け、スコアをSRAMへ保存してください。
エディターで再編集できるデータとROMを用意し、テストプレイ後に調整します。
完成と判断したら、印刷用の箱・ラベルと30秒の宣伝動画を作ります。
```

NOVA SPEARとSTAR CARAVANのテンプレートを起点にできます。テンプレートの複製だけで完成とはせず、指定に合わせて絵・敵配置・ボス・画面を制作します。タイトル画像に埋め込まれた文字も編集対象です。

## 制作から配布まで

1. 要望を作品仕様として整理し、独立したプロジェクトを作る。
2. エディターで再編集可能なデータを作り、実際のGBDKでROMをビルドする。
3. ROMを受け取り、エミュレーターで遊んで修正点を伝える。
4. 完成と判断したROM版を記録する。
5. 指定寸法の印刷用パッケージ、ラベル、実プレイ映像を使う宣伝動画を制作する。

ROMのダウンロードはファイル添付に対応するクライアントで利用できます。会話内のHTML実行はクライアントの機能に依存します。現在固定しているBoytaceanの配布WASMには起動ROMの権利確認事項があり、HTML試遊版の書出しは検査で停止します。詳細は[ライセンス案内](licensing.md)を参照してください。ROM自体のビルドとローカルでの試遊は別の経路です。

画像生成・PDF出力・動画編集には、それぞれ対応する実行機能が必要です。印刷サイズは箱やカートリッジの実寸に合わせ、実際の組立ては試し刷りで確認します。
