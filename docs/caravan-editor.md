# Caravan Editor 操作ガイド

日本語のローカルデスクトップエディタです。Web公開・アカウント・サーバーは不要です。

```bat
bootstrap.cmd
editor.cmd star-caravan
```

起動時はプロジェクトの概要から開始します。開始ステージ、診断、素材数、ビルド状況を確認し、各カードから編集対象を開けます。左のエクスプローラーで素材を選び、中央で編集、右のインスペクターで数値を調整します。検索は全カテゴリの名前・IDを横断します。インスペクターは折りたたみでき、表示設定とビルド構成は次回起動時にも引き継ぎます。「作品を複製」で別IDを作ると初期作品を残して試せます。「新規作品」はSTAR CARAVANをテンプレートにします。IDは英小文字・数字・ハイフン・アンダースコア、表示名は英数字・かなを使います。

保存はCtrl+S、UndoはCtrl+Z、RedoはCtrl+Y（Ctrl+Shift+Z）。F5はビルドしてプレイ、Ctrl+Shift+Bはビルドのみ、Ctrl+Pはコマンド検索です。複製では対象のIDを新しくし、参照先は維持します。素材のPNGも独立します。参照されている対象の削除は検証エラーになるので、先に利用先を変更してください。

## 編集対象

| 対象 | 操作 |
| --- | --- |
| 画像 | 鉛筆、直線、矩形、消しゴム、塗りつぶし、矩形選択、スポイト、左右／上下反転。矩形をコピーして別素材へ貼付。倍率、グリッド、DMG/CGB表示を切替。 |
| PNG | 素材寸法とパレットを先に設定。「PNG取込」で減色数・透明色・切り出し・8×8タイル数を確認して適用。外部原本は変更しません。「PNG書出」は4階調です。 |
| スプライト | 最大32×32、8×8に自動分割。原点・当たり判定・発射位置はキャンバスでも編集。フレームを複製して絵と表示時間を設定。 |
| 自機・敵 | 画像、速度、HP、得点、自機の無敵時間、武器を設定。敵は直線・往復・波形・経路。経路の四角をドラッグし、右で通過時刻を指定。 |
| 弾幕 | 直線・狙い撃ち・扇状・円形・回転連射。弾画像、速度、角度、数、広がり、間隔、回転、遅延、寿命、回数、ダメージ。発射位置は発射元スプライトを参照。 |
| ボス | HP、画像、得点と最大8フェーズ。各フェーズに移動・弾幕・時間／残HPの切替条件。中央上部で経路を編集するフェーズを選択。敵／フェーズの「追加弾幕レイヤー」で独立した弾幕を重ねられます。 |
| ステージ | タイルパレットの画像をクリック、または矢印キー・タイル番号で選びペイント。「壁」→「壁を置く」をONで地形、OFFで消去。イベント一覧を選択し「出現位置」でキャンバス配置。タイムラインをドラッグして時刻変更。マップの1ストロークや出現位置のドラッグは1回のUndoで戻せます。 |
| 画面・HUD | 背景素材、文字、色、配置。文字をドラッグして8pxに整列。HUDは上／下の2行帯。バインドでスコア・残機・時間・ボスHP・上位5件を表示。 |
| 作品設定 | キャラバン／通常、開始ステージ、通常モードのステージ順、ボーナス、爆発素材と時間、出典。 |

マップ寸法と画面文字のX/Yは**タイル単位**、画像寸法はピクセル単位です。背景とタイルセットは先頭フレームのみを使用します。地形は絵とは独立なので、壁らしいタイルも配置してください。自機は地形接触で被弾、両陣営の弾は消滅、敵本体は通過します。

## プレビューとビルド

即時プレビューはビルド不要。「ステージ全体／選択対象」、停止、1f送り、リセット、0.25〜4倍速、シーク、当たり判定を使用できます。選択弾幕の照準をドラッグして狙い撃ちを確認。ボスHPの入力はプレビュー内だけを変更します。シークは入力なしで先頭から再計算し、入力履歴の再生ではありません。

「ROMビルド」はその時点の作品を保存し、CLIと同じコンパイラを別プロセスで実行します。Debug／Releaseを選べます。画面の編集は続けられますが、次の保存はビルド終了まで待ってください。編集が進むと「ROMは編集前の内容です」と表示し、失敗時は新ROMを読み込まず、最後の正常な出力を保ちます。

「ビルドしてプレイ」は保存・検証・コンパイルに成功すると、ROMプレイヤーへ移動して新しいROMを自動起動します。「ビルドのみ」も選べ、中止ボタンでキャンセルできます。中止は実行中の変換・コンパイル工程の区切りで反映されます。

「ROMプレイヤー」はBoytacean WASMで実ROMを実行します。DMG/CGB、再起動、停止、1f送り、音、2〜5倍表示、0.25〜2倍速度を切替。速度1倍以外は消音です。fpsはエミュレーターの処理速度で、ゲームの論理更新速度や実機性能の保証ではありません。キャンバスをクリックして、十字キー、Z=A、X=B、Enter=START、Shift=SELECTで操作します。下のパッドでも操作可能。BGB／Emuliciousボタンは同じ構成のROMを外部で開きます。「ROMを書き出す…」で検証済みROMの保存先を指定できます。ROMの読込・外部実行・書出前に、ビルド構成・作品リビジョン・ファイルのSHA-256を照合します。古い形式のビルド成果物は再ビルドしてください。

ゲームはA/Bで連射、STARTで開始／ポーズ、タイトルのSELECTでスコアボード。全滅でゲームオーバー。有効にしたボス撃破条件でクリアし、時間満了時はボス撃破必須の設定が有効で未撃破ならゲームオーバー、それ以外はクリアです。通常モードは次ステージへ進み、最後にクリア画面を表示します。

自機の武器も弾幕の遅延・回数を使用します。A/Bを押し続ける間を1回のトリガーとして数え、ボタンを離すと次回の遅延・連射回数をリセットします（回数0は無制限）。

## 保存・復旧・オフライン

原本は`projects/<id>/assets-src/game.json`と`images/*.png`。色番号0はスプライトでは透明。PNGは固定4階調、CGB色はJSONへ保存します。外部画像はこの原本領域へコピーされます。

未保存内容は約800ms後に`.cache/editor/recovery/<id>.json`へ保存され、再起動時に復旧を確認できます。復旧コピーはチェックサムを検証し、破損したコピーがあっても正常な保存データは開けます。通常保存は一時ファイル置換とジャーナルで途中失敗を巻き戻します。外部エディターやGit操作で開いた後に原本が変わった場合は、保存・ビルドを止めて上書きを防ぎます。未保存内容は復旧コピーに残るため、外部変更と照合してから作業を再開してください。強制終了時は次の読込で未完了保存を戻します。Git等による原本バックアップも行ってください。

セットアップ後はオフラインで起動・編集・ビルドできます。別フォルダへはリポジトリ全体をコピー。オフラインで依存を再展開するには`.downloads`と`.cache/npm`も必要です。

```bat
bootstrap.cmd -Offline
doctor.cmd
build.cmd caravan-lab -Configuration Debug
```

設定は`.cache/editor`、依存は`editor/node_modules`、アプリ生成物は`editor/build`です。恒久PATH・レジストリは変更しません。

## 制約・未検証

- 論理更新は60 ticks/秒基準、座標1/16px、発射方向22.5°単位。**現在はDMGで処理落ちがあり、ゲーム内120秒＝実時間120秒の性能保証は未達**です。論理順序の一致と実時間の速度は別検査です。
- 敵／ボス1フェーズに基本弾幕1本＋追加レイヤー3本まで。各弾幕の間隔・遅延・繰り返しは独立し、発射元スプライトの複数発射位置を共有します。
- 矩形画像を8×8へ分割する方式で、非矩形メタスプライトの自由なタイル配置専用UIはありません。
- 素材64、パレット8、スプライト全フレーム計128タイル、画面の背景＋文字128タイル、ステージ背景＋HUD128タイル。フレーム16、敵定義32、弾幕32、ボス8、ステージ16。
- 実行時は敵8、ボス1、自機弾6、敵弾16、爆発4、合計31枠とOAM40で生成制限。走査線10超えは計数し、実際の欠け方はROMで確認。CPU予算は静的に保証しません。
- 英数字・ひらがな・カタカナ・一部記号。美咲ゴシックの使用文字だけを各画面へ組み込み、漢字は拒否。CGB色はRGB555へ変換。
- `seed`は将来の乱数用で、初版の編隊・移動には乱数を使用しません。
- スコアは65535で飽和、上位5件はSRAM保存に対応。BGM制作、汎用スクリプト、ノード編集は対象外です。
- 実機DMG/CGBは未確認です。配布前に処理速度・描画・入力・音を確認してください。

## 開発・回帰検証

```bat
cd editor
npm start -- star-caravan
npm run check
npm run build:release
```

`npm start`はアプリを再ビルドしてリポジトリ内のポータブルElectronを起動します。`npm test`はコア検証に加えて、GBDKがあればROM／統合テスト、Windows上でBGBもあればBGBテストを実行します。不足ツールによる省略は明示されます。`test:core`、`test:rom`、`test:bgb`で個別実行できます。ROM生成物や取得ツールはGitへ含めません。

ステージイベントの時刻は0〜「秒数×60−1」フレーム。編隊の最後の敵も終了前に収まる必要があります。展開後の敵／ボス出現は1ステージ1024件までです。診断パネルはエラーと警告を分け、対象をクリックすると該当項目へ移動します。

## NOVA SPEARと新しいゲーム設定

`editor.cmd nova-spear`で3ステージの完成作品を開きます。A（キーボードZ）は広範囲、B（X）は低速移動と集中ショット、START（Enter）は開始／一時停止です。詳しいステージ構成と得点は[作品ガイド](../projects/nova-spear/README.md)を参照してください。

自機インスペクターの「Bボタンの集中ショット」と速度で副武器を指定できます。「なし」なら従来どおりA/Bとも同じ武器です。両押し時はBが優先され、切替時は選択した武器の開始遅延と連射回数をリセットします。集中弾は高威力の通常弾で、貫通弾ではありません。

プロジェクト概要のBGM欄でタイトル／スコア、ボス、クリア、ゲームオーバーの曲を選び、各ステージで道中の曲を選びます。既存作品で未設定なら無音です。BGMは矩形波CH2と波形CH3、効果音はCH1とノイズを使います。内蔵7曲の選曲に対応し、任意の曲の編集・インポートは未対応です。

ステージの「時間内のボス撃破を必須にする」を有効にすると、未撃破のまま制限時間を迎えた場合はゲームオーバーになります。「ボス撃破でステージクリア」と併用できます。未撃破で「終了」イベントへ到達した場合も失敗になります。無効の作品は従来の時間満了クリアです。

「DMG階調レジスター」は0〜255で、画像の色番号0〜3に対応する2bitずつの階調を指定します。従来値228（0xe4）は明→暗、NOVA SPEARの27（0x1b）は暗→明です。スプライトの色番号0は透明のままです。DMG素材表示・シミュレーション・ROMに同じ設定が適用されます。
