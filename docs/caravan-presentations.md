# 会話・クリア演出を含む作品の読み込み

作品フォルダーを `projects/<作品ID>/` に置き、エディタの作品一覧から選択します。
必須ファイルは `project.json`、`assets-src/game.json`、そのJSONが参照する `assets-src/images/*.png` です。
ZIPを直接開く形式ではありません。同名作品がある場合はコピー前にバックアップしてください。
ソース版は `editor.cmd <作品ID>` でも開けます。

東方v0.5の分離プロジェクト（touhou-kouma）で使う次のオプションに対応します。

| 編集データ | 機能 |
|---|---|
| ステージの `presentation` | 立ち絵背景付き会話、Aで送り・STARTでスキップ、クリアボーナス計算 |
| ステージの `parallax` | ROMに事前計算したタイル差分による視差背景 |
| ステージの `bossMusic` | ステージ別ボス曲。省略時は作品共通のボス曲 |
| 作品の `ending` | 複数の背景画像によるエンディング。Aで次へ、STARTで終了 |
| 作品の `performance` | 作品固有の同時出現上限。省略時は敵12・自弾6・敵弾32・演出4 |
| 作品の `music.victory` | ボス撃破ジングル。省略時は従来曲 |

会話・視差・エンディングのない既存作品は従来の構成で動作します。
会話は各ページの文字タイルを共通化し、ページ送りでLCDを停止せず本文行のみを更新します。
全画面の画像・文字は最大255タイル、ゲーム中の背景・スプライト制約は従来どおりです。
画面設定を増やすとROMバンクの容量上限に達する場合があります。ビルド時に容量超過を検出したROMは採用されません。

ゲームの元PNG・設定JSONはプロジェクト側に保存します。エディタ本体やエンジンを作品フォルダーへコピーする必要はありません。
ビルド済みエディタを利用している場合、この対応を含む版へ更新してください。
ソースから起動する場合はmain更新後に `npm --prefix editor ci` と `npm --prefix editor run build` を実行します。

セーブ形式と作品IDは変更しません。東方v0.5の配布プロジェクトは内容を変更せず読み込み・再ビルドできます。
追加曲は従来と同じ組み込み曲選択方式です。任意の音楽ファイルを取り込む機能ではありません。
