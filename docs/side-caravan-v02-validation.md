| バリア | Hで1枚、最大3。被弾で1枚消費して残機・強化を守り、45更新無敵。装着画像は自機の既存OAMを使う。枚数・無敵時間・画像・ドロップを編集可能 |

サンプルは破壊物281個、7種類のアイテム、3段階のボス、全破壊・全取得時の上限38,320点。23素材・28枚のPNGはすべて編集用の4色データで、新規6枚はオリジナルのピクセル絵。BGMは既存のオリジナル曲を選曲した。

RAMは静的領域＋shadow OAMが7,091/8,192バイト、空き1,101バイト。従来のスタック予約1,024バイトを維持。v0.1からの増加は25バイト。巨大BGモードは既存BG描画の作業領域を再利用し、大きな追加バッファを確保しない。通常スプライト素材は33タイル。巨大ボスは実OAMへ描かないが、共通プールの予算計算は弱点素材分を保守的に計上する。

## 負荷測定と残る制約

通しプレイの1ゲーム更新あたり表示フレーム数は次のとおり。小さいほど更新頻度が高い。読み込み・区間移行も含む測定で、固定60fpsではない。

| 区間 | DMG平均 | CGB平均 |
| --- | ---: | ---: |
| 接近 | 1.865 | 1.148 |
| 甲板 | 2.168 | 1.246 |
| 炉心 | 2.336 | 1.284 |
| 巨大ボス | 2.560 | 1.563 |
| 全体 | 2.136 | 1.235 |

全体の最大間隔はDMG 24／CGB 27表示フレームで、区間・ボス画像の読込みを含む。ボムがゲーム更新を止める構造は廃止したが、処理負荷による間隔変動は残る。移動補間は座標の段差を改善するもので、全場面60fpsを保証する変更ではない。

通常ROMの最大値はプールOAM15、1走査線9、自弾9、アイテム3、画面内破壊物68。生成見送りは0。破壊描画は従来どおり1更新8タイルまでで、ボム時に最大46物体が更新待ちとなり、最後の反映まで最大23追加ゲーム更新を要した。判定・得点は発動時に確定し、未転送分は保持する。点滅の間も元のゲーム画面が動く。

既存の独立したstressベンチマークはDMG平均2.953675（基準2.9）、CGB 1.926838（基準1.85）で**未達**。各720状態のC/TS照合は成功した。基準を緩めていない。初版の記録2.935342／1.886838より約0.62％／2.12％増加している。この高負荷試験は敵弾32発・OAM37・1走査線22・生成見送り184の意図的な過負荷配置であり、サンプルの通常進行の数値とは別。初版で未達だったBG64専用の厳格な性能基準は、今回再測定していない。

巨大BGボスの弱点座標は画像原点からX±64／Y±32ピクセルの範囲。弾は最大32発、画像固有タイル＋HUD＋弾用64タイルの合計256まで。フェーズ間カットインは非対応。従来の背景なしBG弾幕モードは最大64発のまま。バリア装着画像は自機と同じ寸法・原点とし、複数機体選択作品では画像差替えを設定できない。

人による操作感・聴感、実コントローラー、DMG/CGB実機、Emulicious上の動作は未確認。タイトルPCMの非ゼロ出力とBGM選曲は自動検査済みだが、人が聴いて品質を評価した証拠ではない。ゲーム承認や公開リリースは行っていない。

## 再実行と証拠

基本手順はルートで`doctor.cmd`、`clean.cmd hello-gb`、`build.cmd hello-gb -Configuration Debug`、`test.cmd`。続いてSIDE／STARのReleaseをビルドする。エディターは`npm --prefix editor run build`、`run typecheck`を使う。

- `.tools/node/node.exe editor/tests/horizontal-ui-run.mjs`
- `.tools/node/node.exe editor/tests/project-ui-run.mjs`
- `.tools/node/node.exe editor/tests/side-caravan-play.acceptance.mjs projects/side-caravan/build/Debug/side-caravan.gb .cache/side-v02/recheck-play --exercise-miss`
- `.tools/node/node.exe editor/tests/side-caravan-native.acceptance.mjs projects/side-caravan/build/Debug/side-caravan.gb .cache/side-v02/recheck-bgb`
- `.tools/node/node.exe editor/tests/stg-benchmark.mjs . .cache/side-v02/recheck-benchmark stress --check-budget`（現状は性能基準で失敗する）

実行ログとスクリーンショットは`.cache/side-v02`および機械可読記録の`evidence`に記載したローカルパスへ保持した。ソース・エンジン・PNG・ROMのSHA-256も機械可読記録へ保存した。[初版の報告](side-caravan-validation.md)は履歴として維持する。
