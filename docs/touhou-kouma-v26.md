# 東方紅魔郷 GB v0.26 — リセットとカットイン

- START＋SELECT＋A＋Bの同時押しでソフトリセット。認識すると画面と音を止め、4ボタンをすべて離すとロゴから再起動する。ゲーム進行・一時変数・割り込みハンドラーはGBDKのCRT初期化でリセットし、ランキング用SRAMは消去しない。GBCは標準速度に戻してから初期化し、通常起動処理で倍速を再設定する。
- 道中、ボス戦、ポーズ、会話やカットインの待ち処理から共通の音声同期処理を通じて受け付ける。起動動画のPCM専用ループ中は従来どおりスキップ扱いとなる。
- 攻撃名をカットイン下部の余白へ中央揃えで配置。1行はy=128、長い2行の名称はy=120/136。ROM生成、ボス編集画面、シミュレーターで同一の配置関数を使う。既存イラストは変更しない。
- 効果音は強いノイズの打撃を外し、弱い立ち上がりから上昇する音程と音量、下降して消える余韻を持つ72フレームのオリジナル音へ変更。パルス1と小音量のノイズを使い、BGM用パルス2・波形3は継続する。市販ゲームの音源は使用していない。

検証結果、ROMハッシュ、画面キャプチャおよびエミュレーターのAPUから収録したWAVは `projects/touhou-kouma/touhou-kouma-design/qa-v26.json` と `presentation-v26` に保存する。音の印象についての人による聴取、実機DMG/CGBの確認は別途必要。

## 検証

- 内蔵エミュレーターのDMG/CGBで、ボス戦・ポーズ・カットインから計6回のリセット、押しっぱなしの消費、A+Bだけではリセットしないこと、再起動後の機種判定とランキング値を確認。
- BGBでもDMG/CGBの両モードで、実入力によるゲーム開始→4ボタン→ロゴ→動画→タイトルを確認。GBCの倍速復帰も確認。
- 全21名称の配置、DMG/CGBのカットイン実画面、APUの音量変化とWAV出力を確認。WAVにはBGMと再開直後のゲーム音も含む。
- 前回のHUD・常駐スプライトVRAM検査、起動動画の完走／スキップ検査は両機種で成功。
- `doctor.cmd`は警告0。`test.cmd star-caravan`は141件成功・失敗0。hello-gbのclean/Debug、star-caravanのDebug/Releaseを実施。
- EmuliciousはDAP EvaluateRequestのNullPointerExceptionで実行検証できなかった。

効果音追加当初に発生した固定ROMバンクの容量超過は、演奏処理をバンク切り替え可能な演出処理へ移して解消した。固定ROMの空きは77バイトで、今後の機能追加もバンク配置に注意が必要。静的RAM＋OAMは7,166バイト、スタック用1,024バイト以上を維持する。
